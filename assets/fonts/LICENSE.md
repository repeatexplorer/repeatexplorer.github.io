# Fonts

Self-hosted rather than loaded from Google's CDN: hotlinking fonts.googleapis.com
sends every visitor's IP address to Google, which an EU institutional site should
not do without consent.

- **Space Grotesk** (display) — SIL Open Font License 1.1.
  <https://github.com/floriankarsten/space-grotesk>
- **Public Sans** (body) — SIL Open Font License 1.1.
  <https://github.com/uswds/public-sans>

Latin subset only, variable woff2: one file per family covers every weight.
