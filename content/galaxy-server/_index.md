---

Most of the tools run in a browser on the public RepeatExplorer Galaxy server, so
nothing has to be installed. Registration is free and is required to submit jobs.

The server is provided as part of the ELIXIR CZ research infrastructure and is
operated by [CESNET](https://www.cesnet.cz/) and
[CERIT-SC](https://www.cerit-sc.cz/).

## What is available there

Every tool marked as available on Galaxy in the [tools section](/tools/) runs on
this server, from read clustering through to whole-genome repeat annotation. The
same tools can be installed locally from their repositories if you prefer to run
them on your own machine or cluster.

## Data and job limits

Job size and storage quotas are set by the server, not by the tools, and they
change as capacity changes. The current limits are stated on the server itself.
Analyses of large read sets or large assemblies are better run from the command
line.

## Acknowledgement

If the server was used for published work, please acknowledge ELIXIR CZ alongside
the citation for the tool itself, which is listed on each tool's page.
