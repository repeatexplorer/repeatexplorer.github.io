Annotates DNA transposons carrying terminal inverted repeats. It starts from the
transposase domains reported by DANTE and searches outward for the inverted
repeats that delimit the element, which identifies complete TIR elements and
their superfamilies.

## Output

- A GFF3 file of TIR elements
- An HTML report summarising the annotation
