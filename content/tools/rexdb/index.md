A reference database of transposable element protein domains from plants, with a
classification system based on the phylogeny of those domains. DANTE and the
pipelines built on it use REXdb to assign elements to lineages, so the database
determines the vocabulary the annotation is reported in.

## Output

REXdb is data rather than a program. Each release provides:

- A FASTA file of protein domain sequences
- A classification table mapping each sequence to its lineage
